The agent drafts it. You answer the interview.

Three moves, in order, every time this blueprint gets installed into a new project.

Install

One command

Drops the blueprint folder into your project. No git clone, no npm install.

Interview

One question at a time

What the product does, who uses it, whether money or a model is involved.

Draft

Every rules file rewritten

Concrete, product-specific rules with the reasoning behind them, not generic filler.

Nine files, one legend.

Everything the agent writes into rules/, plus the one file it deletes by default.

data-models.md
Tables, columns, constraints, and what's computed instead of stored.
business-logic.md
The algorithms and formulas that aren't obvious from the schema alone.
api-routes.md
Every route, grouped by purpose, with its own real error cases.
auth.md
Session mechanics, roles, and how account deletion actually behaves.
security-practices.md
Rate limits, input validation, and row-level security policies.
engineering-standards.md
Stack, project structure, and deployment, reasoned from real needs.
testing.md
The test pyramid, and what CI actually runs on every pull request.
observability.md
Logging, error tracking, metrics, and the two health-check routes.
error-handling.md
One response envelope and status-code conventions, shared everywhere.
llm-integration.md
Optional. Kept only when the product genuinely calls a model.

Install

No git clone, no npm install. Just curl and tar, or PowerShell.

macOS · Linux · git-bash · WSL 
curl -fsSL https://raw.githubusercontent.com/DMK980/Blueprints/main/install.sh | bash -s -- backend
Windows PowerShell 
iwr -useb https://raw.githubusercontent.com/DMK980/Blueprints/main/install.ps1 -OutFile install.ps1
.\install.ps1 backend
